**MatrixNode** 是一套专为高强度跨境业务矩阵、多端设备环境（iOS/Android）量身定制的**纯前端代理资产调度与分发引擎**。

彻底解决传统表格分发节点易出错、输错密码、风控盲区等痛点，实现端到端的订阅分发、地理位置校验与自动化台账闭环。

---

## ✨ 核心特性 (Core Features)

- 🔒 **端到端纯本地沙盒解析**：核心协议注入（Egern / v2rayNG）及二维码渲染均在浏览器物理内存中完成，零后端服务器流转，彻底杜绝核心资产外泄。
- 🚀 **毫秒级台账直通车 (Data Pipeline)**：支持一键灌入数百行原始节点数据（`IP:端口:账号:密码`），全自动排版清洗。
- 🌍 **并发级物理归属地反查**：内置免鉴权高频位置校验引擎，将 IP 实时翻译为精确的纯中文「国家+城市」，防范死号风控红线。
- 📋 **无缝兼容 Excel / 飞书表格**：生成结果一键复制，自动匹配 7 列标准表格制表符，实现多端数据对齐闭环。
- 🎨 **苹果级毛玻璃 UI 与流体科幻视效**：
  - 纯粹的 Glassmorphism（玻璃拟态）极简高级 UI 设计。
  - 内置昼夜双轨主题，夜间模式激活底层 **Canvas 粒子物理引擎**（动态星云、流星雨与巡洋舰编队）。
- 👁️ **隐形风控审计大屏 (Admin Dashboard)**：支持静默拦截终端操作流水，并通过密令挂载云端 Google Apps Script，实现全矩阵设备的访问打表与行为溯源。
- 🛠️ **隐藏式内容管理后台 (CMS)**：解锁后可直接在线管理 WiFi 卡片（改名称/换二维码/增删）、背景音乐歌单、站点背景与粒子特效、使用教程正文，保存后全员实时生效，无需改代码、无需重新部署。
- 📱 **移动端全面适配**：手机浏览器打开即可使用，卡片/表格/弹窗/悬浮控件均做了小屏重排，后台也可在手机上操作上传。

## 🛠️ 快速部署 (Deployment)

本项目为 **100% 纯静态前端项目**，无需配置任何 Node.js/Python 运行环境或数据库。

### 方法一：直接本地运行
1. 克隆或下载本项目压缩包到本地。
2. 解压后，双击打开 `index.html` 即可在浏览器中丝滑使用。

### 方法二：使用 GitHub Pages 免费云端部署（推荐）
1. Fork 或上传此项目到你自己的 GitHub 仓库。
2. 进入仓库的 **Settings** -> **Pages**。
3. 在 `Build and deployment` 下的 `Source` 选择 **Deploy from a branch**。
4. 将 Branch 设置为 `main`，文件夹选择 `/(root)`，点击 **Save**。
5. 等待 1-2 分钟，GitHub 会自动为你生成一个永久免费的安全 HTTPS 在线访问链接。

## ⚙️ 部署云端后台：审计大屏 + 内容管理 (Google Apps Script)

为了满足团队管理中“盯着数据拿结果”的需求，系统通过 Google Apps Script 打通了 Google 表格与 Google Drive。
**你不需要额外的服务器，GitHub Pages 静态托管即可拥有完整后台能力。**

### 1. 部署后端脚本

1. 打开你的 Google Sheets（谷歌表格），菜单 `扩展程序` -> `Apps 脚本`。
2. 把本仓库 `apps-script/Code.gs` 的**全部内容**粘贴进编辑器（替换默认代码）。
3. 顶部配置区按需修改：
   - `ADMIN_TOKEN`：后台管理密钥（默认 `Qq112233`，**强烈建议改成自己的**）。
   - `SPREADSHEET_ID`：留空即可（使用脚本所绑定的表格）。
   - `LOG_SHEET_NAME`：流水工作表名，默认 `MN_Logs`（不存在会自动创建，不会动你原有的工作表）。
   - `UPLOAD_FOLDER`：Drive 上传目录，默认 `MatrixNode_Uploads`。
4. 右上角 `部署` -> `新建部署` -> 类型选 **Web 应用**：
   - **执行身份**：我
   - **访问权限**：**任何人**（否则前端无法上报）
5. 首次部署会要求授权，同意后复制生成的 **/exec 结尾的 URL**。

### 2. 挂载前端

打开 `js/main.js`，把第一行的 `REPORT_API_URL` 换成你自己的 URL：

```js
const REPORT_API_URL = "https://script.google.com/macros/s/你的部署ID/exec".trim();
```

### 3. 解锁后台

在网页左上角 `🌐 Logo` 处**连续快速点击 5 次**，输入密钥即可解锁 **「🔒 审计大屏」**，其中包含：

| 模块 | 能力 |
| --- | --- |
| 🎛️ 数据看板控制台 | 在线人数/累计服务数的真实或自定义模式、前台模块显隐 |
| 📈 趋势图 | 全员出勤访问与交互频次 |
| 🛠️ 站点内容管理台 | WiFi 卡片、前置代理、公司 WiFi、音乐、背景、教程 |
| 📋 流水表格 | 全量访问与操作记录溯源 |

> 密钥一次输入后保存在本机浏览器，下次打开大屏无需重复输入（换设备需重新输入）。

### 4. 后台能改什么

- **📶 基础网络卡片**：改名称 / 改密码 / 换二维码图片 / 改角标 / 高危标红 / 增删卡片。
  - 勾选「用 WiFi 协议自动生码」时，不依赖图片，系统按 `SSID + 密码` 现场生成可扫码直连的二维码。
- **🌐 前置代理 & 🏢 公司 WiFi**：改名称、换二维码图片、增删条目。
- **🎵 背景音乐**：上传 mp3 或填外链，增删曲目，可一键关闭播放器（手机端更省流量）。
- **🎨 背景与视效**：可切换为自定义背景图（日间/夜间各一张），可关闭粒子特效（手机省电流畅）。
- **📖 使用教程**：直接编辑正文，**支持 Markdown 或 HTML**（自动识别），带快捷插入工具条与预览。
- **📝 版面文案**：「代理 & WiFi」区块标题与提示文字可改，提示留空即隐藏。
- **✨ 卡片动效**：每张卡片可单独选 8 种动效（流光/霓虹/渐变/漂浮/脉冲/静止…），另有一键全局关闭。
- **🔢 排序 + 自动归类**：四个列表（基础网络卡片 / 前置代理 / 公司 WiFi / 音乐）都支持 ↑ ↓ 排序；后台会按「有没有二维码」自动分组显示（WiFi 协议生码 / 图片二维码 / 纯文字卡），条目再多也能一眼找到。
- **❓ 每张卡片的问号教程**：可选图片教程（传图或外链）或文字教程（支持 Markdown），也可关闭。

上传的文件存放在你的 **Google Drive `MatrixNode_Uploads` 目录**（单文件 ≤ 8MB，脚本会自动设为“任何人可查看”）。

### 5. 数据记录在哪里、怎么查看

- 所有人访问页面、生成二维码、批量打表、代理检测、提交建议，都会即时写入你的 **Google 表格的 `MN_Logs` 工作表**（一行一条，时间按北京时间）。
- 查看方式任选：
  1. 直接打开 Google 表格的 `MN_Logs` 页签（含「时间/类型/操作IP/地区/操作人/行为/详情/UA」可读列）；
  2. 网页里解锁 **🔒 审计大屏**，点「🔄 同步云端流水」查看表格 + 趋势图。
- 你原有的工作表不会被改动或删除。

## 📱 手机访问

直接用手机浏览器打开站点地址即可：

- 顶部标签栏可左右滑动；卡片自动变为单列/双列；表格可横向滚动；弹窗按屏宽自适应。
- 音乐台在触屏下保持收起状态，**点一下唱片**即可播放/暂停。
- 手机也能解锁后台：连点 Logo 5 次 → 输入密钥 → 在「🔒 审计大屏」底部使用内容管理台（可直接调用手机相册上传二维码）。
